Fulgurite will be a real-time 3D electromagnetism simulation engine written in C++. It will focus on modeling electric and magnetic fields, charged particle dynamics, and field interactions using numerical methods.

The goal of the project is to build a physically grounded computational environment for visualizing and experimenting with classical electromagnetism. Its intended use is as a physics simulation system

Overview

Fulgurite begins with the fundamentals of electrostatics and gradually expands toward full electromagnetic field simulation. The long-term goal is to implement a numerically stable approximation of Maxwell’s equations in a discrete 3D space.

The engine will be designed around:

Charged particle simulation
Electric and magnetic field computation
Numerical integration of motion
Real-time visualization of vector fields
Current Status

The project is in early development. The initial focus is on establishing a stable foundation for:

Point charge interactions
Electric field calculation
Basic visualization pipeline
Numerical stability for particle motion

Magnetism, induction, and wave propagation are planned future additions.
